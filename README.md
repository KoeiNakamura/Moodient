# Moodient (ムーディエント)

> 感情を固定的なラベルではなく、グラデーションとして記録するパーソナルジャーナリングWebアプリ。

---

## コンセプト

日常の些細な出来事やその時の感情を、ひとことメモと気分の数値（2軸）で記録し、過去の自分を客観視することを支援するツール。
長期的にはユーザーの感情の安定化をサポートするアプリとしたい。

* **かんたんな記録**: ひとことメモだけでも保存可能。気分の入力は任意で構わない。
* **非自己批判的な観察**: ネガティブな感情も、ありのままの色でTLに可視化。
* **過去の自分をリソースに**: 以前落ち込んでからどう立ち直ったかをTLから振り返られる。

---

## 感情モデルとグラデーション表現

心理学的**2軸モデル（Valance × Arousal）**を採用し、感情の座標を計算してCSSグラデーションへ変換。

* **Valence (快・不快)**: $-1.0$ (不快・つらい) $\sim$ $+1.0$ (快・楽しい)
* **Arousal (覚醒度)**: $-1.0$ (落ち着き・疲労) $\sim$ $+1.0$ (緊張・興奮)

※気分が未入力のメモはデータをスキップして、TL上で前後の有効なログの色同士をスムーズにグラデーション保管して描画する。

## 技術スタック

### Frontend
* **Next.js (App Router)**: Reactベースのフロントエンドフレームワーク
* **TypeScript**: 型安全なJavaScript開発
* **Tailwind CSS**: 柔軟なUIスタイリング

### Backend
* **Python 3.11 / Django 5.0**: Webアプリケーションフレームワーク
* **Django REST Framework (DRF)**: JSONデータを返すAPIサーバー構築

### Database & Infrastructure
* **PostgreSQL**: リレーショナルデータベース
* **Docker / Docker Compose**: コンテナ化によるローカル開発環境の統一
